# macOS Security Compliance Project content

`catalog.json.gz` is generated by `cmd/mscp-import` from the
[macOS Security Compliance Project](https://github.com/usnistgov/macos_security) (mSCP), release noted in
the catalog's `release` field.

**Changes made:** rule and baseline YAML were converted to a compact JSON catalog. Only the fields VibeMDM
needs were kept (id, title, discussion, references, tags, platforms/benchmarks, check/fix scripts, expected
results, organization-defined values, configuration-profile content). Files containing
"Vendor Description content Copyright … Apple Inc." are excluded by the importer, because that content is
not licensed under CC BY 4.0.
